AV-01 — System Objective & Architecture

Convert real-time or simulated sensor detections into explainable driving guidance. The system does not merely register that something is present; it reasons about what that presence means for the vehicle's next move and justifies that reasoning to a human observer.

SENSE → ASSESS RISK → PLAN → RECOMMEND → CONFIDENCE → EXPLAIN → LOG
